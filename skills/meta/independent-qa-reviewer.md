# Proposed Skill: Independent Skeptical Creative + Release Reviewer

**Input:** frozen project manifest, ledger/source hash, approved script, scenes, assets/licenses, final audio, subtitles, final MP4, publication metadata, provenance, review history.  
**Output:** reason-coded findings with hard blockers, suggested minimal fix, evidence and approval hash chain.

## Two independent reviewer modes
**Deterministic reviewer**: JSON/schema, file existence, FFprobe & FFmpeg decoding, source hash chain, duration/aspect/crop, subtitle and text language, audio channel/silence/clipping, copyright/licensing/AI label presence, render scene frame samples, channel/format/status preflight and dedupe. Anything critical fails closed.

**Editorial reviewer**: question relevance, US/culture English, real viewer value, nuance, factual accuracy vs ledger, hook/payoff, semantic image matching and ethical framing. This is a meaningful second opinion with explicit evidence, not self-congratulation. Human review for early canaries required.

## Scorecard (100; project-defined target not platform guarantee)
| Dimension | Weight |
|---|---:|
| Claim truth/freshness/uncertainty | 20 |
| Native English + US/Canada nuance | 20 |
| Viewer value and original insight | 15 |
| Hook-story-payoff honesty | 10 |
| Claim-to-visual relevance and scene craft | 15 |
| Voice/captions/readability | 10 |
| Rights, AI disclosure and publishing metadata | 10 |

**Recommended editorial progression criterion:** score >=85/100, each dimension >=60% of own weight; early pilot requires human pass. Any deterministic hard blocker overrides score. A high score does not imply YouTube algorithm or monetization approval.

## Reviewer must challenge
- "Can a viewer verify this from what we show?" / "Are prices and availability actually valid for the US?" / "Does visual imply proof it doesn't contain?" / "Would a US English speaker say that naturally?" / "Does the headline imply a result not demonstrated?" / "Will this look like the last 10 generic slideshow videos?" / "Do we have rights for every imported asset?" / "Does the upload go to correct channel and remain Private?"

## Repair loop
List failing scene, script span, claim IDs, evidence and downstream hash dependencies. Apply bounded maximum two revisions in a pass. Re-run deterministic tests after each revision, invalidate any stale approvals. Escalate third iteration or disagreement to human. Do not turn off rules to force completion.

## Review output schema example
```json
{
  "reviewer_kind":"model_precheck",
  "source_hashes":{},
  "score":null,
  "hard_blocks":[{"code":"VISUAL_CLAIM_MISMATCH","scene":"V03","evidence":"frame-sample.png"}],
  "advisories":[],
  "fix_order":[],
  "human_approval":false,
  "verdict":"BLOCKED"
}
```

**Important:** This reviewer MUST have independent evidence from actual media, not only text generated by the same writing agent. Never label an automated review as native-speaker/human approval.
